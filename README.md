<h1 align="center">👾 Featured projects</h1>

### [Fake Job Predictor](https://github.com/saksham4data/Fake_Job_Predictor)
A machine learning classification application that analyzes online job descriptions and detects fraudulent postings. Implements text preprocessing, TF-IDF feature extraction, and Logistic Regression with probabilistic risk scores to prevent job scams.

**Stack:** Python · Scikit-Learn · NLP · Pandas · Logistic Regression

---

### [Road Accident Severity Prediction Model](https://github.com/saksham4data/Road_Accident_Severity_Prediction_Model)
A predictive data science system that models traffic accident factors to forecast severity levels. Features exploratory data analysis, class imbalance mitigation, feature importance ranking, and multi-class classification.

**Stack:** Python · Pandas · Scikit-Learn · Seaborn · Matplotlib

---

### [SensorApp — Real-Time Telemetry Utility](https://github.com/Saksham-27-SN/SensorApp)
An Android application interfacing directly with onboard hardware sensors (accelerometer, gyroscope, proximity) to stream and visualize live motion telemetry.

**Stack:** Java · Android SDK · SensorManager API · Gradle

---

### [Currency Converter](https://github.com/Saksham-27-SN/CurrencyConverter)
A clean, object-oriented Android mobile app delivering responsive multi-currency calculations with reliable state handling and modern Gradle build architecture.

**Stack:** Java · Android SDK · XML Layouts · OOP

---

### [June — Personal AI Assistant](https://github.com/saksham4data/June_Personal_AI_Assistant)
A desktop assistant engineered for automated task handling, system command triggers, and everyday workflow acceleration.

**Stack:** Python · JavaScript · HTML/CSS · Automation
